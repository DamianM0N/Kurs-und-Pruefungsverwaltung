# Kurs und Prüfungsverwaltung

Gruppenprojekt im Studiengang Data Science und Künstliche Intelligenz an der DHBW Karlsruhe.

In diesem Projekt werden Funktionen zur Entwicklung einer Anwendung implementiert, mit der bereitgestellte Studentendaten ausgelesen, bearbeitet und ausgewertet werden können. Außerdem soll die Anwendung die Erstellung von Zusammenfassungen der Daten ermöglichen.
