# Kurs und Prüfungsverwaltung

Gruppenprojekt im Studiengang Data Science und Künstliche Intelligenz an der DHBW Karlsruhe

Entwicklung einer Anwendung zur Verarbeitung und Analyse von Studierendendaten. Die Anwendung ermöglicht das Einlesen, Bearbeiten und Auswerten bereitgestellter Daten sowie die automatisierte Erstellung aussagekräftiger Datenzusammenfassungen.
